# Oracle Party

A mobile-only browser trivia game built for fun, real-time multiplayer experiences.

## Tech Stack

- **Hosting:** GitHub Pages (static front-end)
- **Backend:** Supabase (database, auth, realtime)
- **Languages:** Vanilla HTML, CSS, JavaScript — no frameworks

## Project Structure

- `index.html` — Main entry point
- `styles.css` — All styling
- `supabase-config.js` — Supabase client initialization and configuration
- `CLAUDE.md` — Project documentation and development guidelines

## Development Guidelines

- Mobile-first design — this is a mobile-only game
- Keep things simple: vanilla JS, no build tools, no bundlers
- All static assets served via GitHub Pages
- Supabase handles all backend concerns (database, auth, realtime subscriptions)
